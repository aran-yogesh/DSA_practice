# Revisit

Problems that need more practice. Come back to these after solving more problems in the same pattern.

## How to use this folder
1. Try to solve the problem from scratch without looking at the solution
2. If stuck after 10 minutes, read only the strategy section
3. Code it yourself, then compare with the saved solution
4. Once you can solve it independently, move it to the correct topic folder

## Problems to Revisit

| Problem | Difficulty | Pattern | Why it's here |
|---------|-----------|---------|---------------|
| 84. Largest Rectangle in Histogram | Hard | Monotonic Stack | Hard to visualize width calculation and left boundary tracking |

## Tips for Hard Problems
- Draw the problem on paper first — literally draw bars, pointers, stack state
- Trace a small example by hand (3-4 elements) before coding
- Ask: "what information do I need at each step?"
- Come back after solving 5-10 more problems in the same pattern
